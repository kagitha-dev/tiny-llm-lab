    Where the rows come from

    The embedding weights are learned

    Every row of the embedding table starts as random numbers. Training uses the same task as the Tiny LLM Lab, predicting the next token, and nudges these numbers each time. Each row has 2 numbers, so each token can be drawn as a point: its two numbers are its position on this map.
