Scale

From this mini model to real ones

Same blocks, same training rule. Real models are bigger in every direction and stack the transformer block many times.

A simplified model for understanding: one transformer block with one attention head, and no layer normalization. Real transformers use many heads per block, layer normalization, and dozens of stacked blocks, but every block does the same two jobs shown here: attention moves information between tokens, and the feed-forward network processes it inside each token.
